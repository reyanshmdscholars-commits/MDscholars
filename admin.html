Test Student View Canvas-style impersonation for testing

Log in as a generic Test Student to walk through the portal exactly as a real student would. Any submissions or actions made in this view are flagged is_test_data = true and never affect real reporting. Use the Reset button to wipe all test activity in one click.

1. Provision Test Students

One-time setup. Creates five auth users (one per track), each with a paid student_profile. Idempotent — safe to click again; existing users are skipped.

Click Provision to check current status.

2. Enter Student View

Pick a track and open the portal in a new tab, already signed in as that track's test student. A yellow banner at the top will remind you you're in test mode.

3. Reset Test Data

Deletes every row across submissions, questions, and certificates where is_test_data = true. Real student data is untouched.

Manage Admins Anyone in this list can sign in to admin.html

Add or remove admin users. To promote someone to admin, they first need a Supabase Auth account — apply through the site, sign up for the portal, or use the "Invite a new admin" flow below to send them a Supabase magic-link signup. Their email then gets added to the admin_users allowlist.

Add / promote an admin

Enter an email that already has a Supabase Auth account (any student, mentor, or new signup). We look up the auth user and add them to admin_users. If the email has no account yet, click Invite — we send them a magic-link signup, then you can promote them once they've signed up.
